# Órbita Rodante

Aplicación móvil para la gestión de vehículos seminuevos.

## Tecnologías

- React Native
- Expo
- TypeScript
- Node.js
- Express
- MySQL
- Docker

## Arquitectura

Clean Architecture

src/
├── domain
├── data
├── presentation
└── shared
presentation → Pantallas
domain → Reglas de negocio
data → API y base de datos
shared → Código reutilizable
## Versión Actual

v1.0.0

## Funcionalidades

- Login
- Gestión de Vehículos
- Gestión de Clientes
