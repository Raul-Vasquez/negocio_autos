## Pantalla Bienvenida

La aplicación iniciará con una pantalla de presentación.

Elementos:

- Imagen de fondo completa
- Logo Órbita Rodante
- Frase comercial
- Botón Comenzar

El diseño tomará como referencia aplicaciones modernas de automóviles con estilo premium.

El botón Comenzar dirigirá al usuario hacia la pantalla de Login.
